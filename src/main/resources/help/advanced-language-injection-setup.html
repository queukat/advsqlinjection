Advanced Language Injection setup guide

Advanced Language Injection applies IDE language support to structured values when a configured rule matches the current file and value prefix.

Create a rule

  1. Open Settings and search for Advanced Language Injection.
  2. Click Add to create a rule from scratch, or Add SQL example for a SQL preset.
  3. Choose the target language registered in the IDE, for example SQL, RegExp, GraphQL, or another installed language.
  4. Set a file pattern such as *.yaml or *.json.
  5. Use path-aware matching when only a specific folder should be affected, for example config/**/*.yaml.
  6. Use Preview current file to confirm the selected rule matches values in the active editor.

Example

query: "sql:select * from users where active = true"

For this value, a rule with prefix sql: and language SQL injects SQL after the prefix.

YAML block scalar example

snippet: |
  SELECT * FROM users WHERE active = true

For YAML block scalars, use prefix snippet: |. The rule matches the YAML header line and injects into the block body.

Limits

  • Only PSI elements that support IntelliJ language injection can be injected.
  • Plain text files are not supported by the IntelliJ Platform injection host model.
  • Rules are prefix and path based; they do not inspect YAML or JSON schemas.
